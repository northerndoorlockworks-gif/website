The right lock for each door

We match the lock to the door

A property rarely has one kind of door. We look at each one and pick the lock that fits it and fits how you manage the place.

  • Standard deadbolt doors. A Wi-Fi keypad deadbolt is usually the best value.
  • Multipoint and mortise doors. INOX smart locks fit the doors a standard smart deadbolt can't. See keyless entry for multipoint and mortise doors.
  • Keys where you still want them. Keypad locks can be tied into a master key system, so maintenance still has one key that opens everything. For keys that can't be copied, see key control.
